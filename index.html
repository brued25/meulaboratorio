Sobre

Este site é um espaço para reunir projetos, demos e notas. Edite projects.json para adicionar novas entradas; o site carrega automaticamente os itens.

Como adicionar

  1. Abra projects.json e adicione um objeto ao array com: title, category, description, link.
  2. Faça commit/push no repositório — se você usa o GitHub, habilite o GitHub Pages em Settings → Pages (branch: main / root).
